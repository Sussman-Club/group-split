# Web push notifications

Web push uses the same Firebase project, delivery queue and server-side Admin credentials as Android. Enable Firebase Cloud Messaging and create a Firebase web app and Web Push certificate in the Firebase console. Configure the web host with `WebPush__ApiKey`, `WebPush__ProjectId`, `WebPush__MessagingSenderId`, `WebPush__AppId`, and `WebPush__VapidKey`. These values are public browser configuration, not Admin credentials. Configure the API with `Push__WebBaseUrl` set to the public HTTPS origin (for example `https://groupsplit.example`), in addition to the existing `Push__Enabled`, `Push__ProjectId`, and server-only Admin credential described in [Android push](android-push-notifications.md). The project IDs must match. Provision these environment variables on the respective web and API resources; a missing web setting disables the controls.

The Firebase Cloud Messaging API must be enabled for the project. Restrict the web API key to the deployed site's origins and the APIs Firebase needs. The site must be served over HTTPS. The public origin configured on the API is used for notification clicks; use the actual origin at which people sign in. Do not expose the service-account JSON to the browser.

Alerts are opt-in and preferences apply to this browser on this device. On iPhone and iPad, add the site to the Home Screen and open it from there before enabling alerts; Web Push requires iOS or iPadOS 16.4 or later. Browser and operating-system notification settings can block delivery. Sign-out removes the installation, and deleting an account removes its server registrations.

For a release check, use a configured Firebase project and a real supported browser: enable each category in turn; send an eligible event with the page focused, backgrounded, and closed; follow each notification to its destination; turn a category off and verify delivery stops; then sign out and verify the token no longer receives alerts. Repeat on an iOS Home Screen app when that platform is supported. Check service-worker updates and a second browser profile independently.
